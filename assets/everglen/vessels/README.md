# Everglen Vessel Assets

Expected runtime files:

- `boat.png` - small civilian/fishing vessel
- `sailboat.png` - local/coastal trade vessel
- `sailship.png` - larger merchant vessel

The naval system loads these from `res://assets/everglen/vessels/`.

The supplied pack does not contain dedicated warship art. Military vessels therefore use the `sailship` texture as a temporary fallback until dedicated war-galley/warship assets are added.
